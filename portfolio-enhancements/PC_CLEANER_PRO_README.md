## ⚡ Overview

**PC Cleaner Pro** provides an intuitive, modern desktop interface to inspect disk utilization, scan for disposable cache hierarchies, and safely reclaim gigabytes of storage across both Windows and Linux environments without running third-party commercial adware.

---

## ✨ Features

- 🖥️ **Modern Dark-Mode UI**: Built with `CustomTkinter` offering a clean, responsive interface.
- 📊 **Hardware & Storage Telemetry**: Real-time disk capacity metrics, CPU/memory statistics, and partition breakdown.
- 🔍 **Targeted Cache Scanner**: Safely scans user scratch folders, log directories, browser temp files, and thumbnail databases.
- ⚡ **Safe Exception Handling**: Gracefully ignores in-use or process-locked files without crashing.
- 🐧 **Cross-Platform Support**: Works seamlessly on Windows 10/11 and Linux distributions (Ubuntu, Linux Mint, Debian).

## 🚀 Quick Setup

```bash
# 1. Clone repository
git clone https://github.com/a4ik7/Pc-Cleaner-Pro.git
cd Pc-Cleaner-Pro

# 2. Install dependencies
pip install -r requirements.txt

# 3. Launch application
python main.py
```
