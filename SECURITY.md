## Reporting a Vulnerability

We take the security and integrity of our users' systems very seriously. If you discover a security vulnerability or an unintentional deletion edge case within **Windows Deep Cleaner**:

1. **Do not create a public GitHub issue.**
2. Send an email to the project maintainer: **Abhigyan Sati** via GitHub contact / private advisory.
3. Include:
   - Specific Windows OS version and build (`winver`).
   - Detailed description of the file path, privilege boundary, or scenario.
   - Proof of concept or reproduction steps.

We will acknowledge receipt within 48 hours and work with you to test and release a patch promptly.
